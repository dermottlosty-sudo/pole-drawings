Assessed Products Database

 

Welcome to the Assessed Products Data Base combined and Standards and Assessments.

This data base has been created to assist in providing an up to date list of current assessed suppliers and their manufacturing site/location.

If additional companies’ have been assessed for the same product this will also be shown within the data base

This data base is constantly being updated, however If you are unable to find what you are looking for, please contact a member of the Standards and Assessments team. 

If a product(s) is covered by a Network Product Specification (NPS) the NPS number will be shown within the page title.

NPS documents are held within the companies “Controlled Document System” which resides on the Intranet.
